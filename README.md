# Batch-Rename-Pro-for-AE
A powerful After Effects script for batch renaming items in the Project panel or selected layers in the Timeline. Supports 4 modes: format, replace text, add sequence numbers, and add custom text. Multi‑language (EN, ZH, FR, IT, RU, JA, KO). Developed by ZBT Studio, code by DeepSeek. Free for learning, non‑commercial use only.
